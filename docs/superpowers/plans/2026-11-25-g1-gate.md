# G1 Gate 实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 给消费项目生成一个稳定、平台无关的 gate runner，使用 authored `.agents/gates.yaml` 和技术栈适配的命令，串起 `dab detect --strict`、项目 code/docs 检查；首批增加 Java、iOS、Android 检测。

**Architecture:** scanner 只读检测 stack 和默认命令；`.agents/gates.yaml` 是唯一 authored gate 定义；normalize 把它编译成 `scripts/dab-gates.json` 快照，并生成稳定薄 runner `scripts/dab-check.mjs`。runner 不解析 YAML、不内嵌项目命令，只执行快照并聚合结果。`dab detect` 增加 Verification 组，检查配置、快照、runner 和命令接线。

**Tech Stack:** TypeScript ESM、Node >=24.9、Zod、YAML、Vitest；不新增运行时依赖；不新增 `dab` 命令。

**Spec:** `docs/superpowers/specs/2026-11-25-g1-gate-design.md`

## Global Constraints

- gate 配置始终 project-only；global scope 不生成配置、runner 或快照。
- `.agents/gates.yaml` 是 authored source，只在缺失时生成 starter，永不覆盖。
- `scripts/dab-check.mjs` 是稳定 runner；项目命令只存在于 `scripts/dab-gates.json` 快照。
- 生成物带 `dab-gate` marker/hash；只更新未修改的旧版本，modified/unversioned 保留并 warning。
- 所有 gate 执行完再汇总，不在第一个失败处短路。
- `source` gate 固定 required，始终调用 `dab detect --strict`；不能关闭或静默跳过。
- iOS Xcode 不得猜 scheme/destination；缺少必需字段输出 `CONFIG` 并非零退出。
- Java/Android 优先 wrapper（`mvnw`/`gradlew`，Windows 用 `.cmd`/`.bat`），不静默退回系统工具。
- 不自动写 CI 文件；只提供文档片段和 detect 非 strict warning。
- 不新增 `dab` 命令；不引入网络安装；不改变 manifest `schemaVersion` 或 `.claude` 规则。
- 新行为必须有失败测试；每次提交前跑聚焦测试、`pnpm test`、`pnpm typecheck`。

## Review Focus

- Xcode 缺 scheme/destination 时是否真的 `CONFIG`，而不是假通过。
- Android/SwiftPM/Java 冲突时是否只选一个 primary，且不重复跑 test。
- 稳定 runner 是否只读快照，不把命令写回代码。
- 配置无效/快照损坏/runner 修改时是否零写入或保留 warning。
- `normalize` 的 gate 写入是否在 target planning 前、是否 all-or-nothing。
- `source` 是否在所有路径都执行，不能被 `off` 或缺失 snapshot 绕过。
- detect 的 strict 映射是否与设计一致，且不重复行。

**Interfaces:**
- Produces:

```ts
export interface ResolvedGateCommand {
  command: string | null;
  mode: GateMode;
  needs?: string;
}

export interface GateSnapshot {
  version: 1;
  generated: { dabVersion: string; sha256: string };
  gates: {
    source: { mode: 'required' };
    code: { commands: Partial<Record<GateCommandName, ResolvedGateCommand>> };
    docs: { mode: GateMode; command?: string };
  };
}

export function renderGateRunner(version: string): string;
export function compileGateSnapshot(
  config: GateConfig,
  scan: ScanResult,
  version: string,
): { snapshot: GateSnapshot; content: string; hash: string };

export interface GateArtifactPlan {
  files: Record<string, string>;
  actions: Array<{ path: string; kind: 'create' | 'update' | 'skip'; reason?: string }>;
  diagnostics: Diagnostic[];
  states: Array<{ path: string; status: 'missing' | 'current' | 'stale' | 'modified' | 'unversioned' }>;
}

export async function planGateArtifacts(input: {
  root: string;
  scan: ScanResult;
  version: string;
}): Promise<GateArtifactPlan>;

export async function applyGateArtifacts(
  root: string,
  plan: GateArtifactPlan,
  options: { dryRun: boolean },
): Promise<{ created: string[]; updated: string[]; skipped: string[]; diagnostics: Diagnostic[] }>;
```

- Snapshot canonicalization: stable key order and command order; hash is SHA-256 of JSON.stringify of `gates` in canonical form.
- Stable runner:
  - `readFileSync`/`readFile` `scripts/dab-gates.json`;
  - run `source` first (`dab detect --strict`), then snapshot commands;
  - run all gates, no short-circuit;
  - per-command status/exit/duration;
  - `--json` and `--strict`;
  - DAB binary resolution as design;
  - missing/invalid snapshot → `CONFIG`, exit 2;
  - no project command strings embedded in runner.
- Windows wrapper normalization:
  - `./mvnw` → `mvnw.cmd` on win32;
  - `./gradlew` → `gradlew.bat` on win32;
  - test platform parameter; runner uses `process.platform`.
- Marker:
  - runner header `// dab-gate-runner: <version> sha256=<hash>`;
  - snapshot uses `generated.dabVersion`/`generated.sha256`.
- Plan/apply:
  - missing config → starter; missing runner/snapshot → create;
  - existing runner/snapshot: marker/hash states; only update stale unmodified; modified/unversioned preserve + warning;
  - config authored: never write if exists; invalid config error and no writes;
  - all paths relative and validated with `assertParentInsideRoot`.
- Runner applies command strings with `spawn`/`shell`; no dynamic eval.
