# Style guide / 写作规范

This file is maintained in both languages by design and is excluded from the normal pairing gate.

本文件按双语直接维护，不参与普通配对门禁。

## English

- Use short sentences and concrete verbs.
- Prefer "must" for gates and "should" for advice.
- Keep commands, paths, configuration keys and code blocks unchanged.
- Do not translate code comments inside code blocks.
- Use one term from `terminology.md` for one concept.
- Use DAB for the direction and product, DAD for the current development practice, and `dab` for the CLI.
- End every file with exactly one newline and no trailing whitespace.

## 中文

- 使用短句和具体动词。
- 门禁使用“必须”，建议使用“应该”。
- 命令、路径、配置键和代码块保持原样。
- 不翻译代码块中的注释。
- 一个概念只使用 `terminology.md` 中的一个译法。
- DAB 表示方向和产品，DAD 表示当前开发实践，`dab` 表示 CLI。
- 每个文件只保留一个末尾换行，不保留行尾空格。

## Structure / 结构

- Keep heading levels, list kinds, table shapes and code blocks parallel.
- Update both languages and `.i18n.yaml` in the same change.
- Keep external URLs identical across languages.
- 中英文之间使用半角空格；中文使用全角标点。
